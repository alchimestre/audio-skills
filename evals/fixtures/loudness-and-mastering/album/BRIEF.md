# Delivery brief: single "Half Light"

One mix in `mix-master.wav`, to be prepared for distribution and archive.

## Delivery

| Field | Value |
|---|---|
| Integrated loudness | -14.0 LUFS, ±0.5 LU |
| True peak | -1.0 dBTP or below |
| Distribution master | WAV, 48 kHz, 16-bit, dithered |
| Archive master | WAV, 48 kHz, 24-bit |
| Lossy check | AAC 256 kbps, decoded and measured |
| Record | One line per deliverable: file, rate, depth, LUFS, dBTP, target |

## Constraints

- Nothing in the mix is to be re-balanced; this is a mastering job.
- The client's reference feels louder than the current file.
- No compressed or streaming versions are delivered from this brief.

  mix-master.wav      stereo, 48 kHz, 16-bit
